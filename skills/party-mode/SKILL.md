# Party Mode

## Overview

Run a small multi-role debate so clash surfaces angles no single voice would reach. Orchestrate the room; do not force consensus. The point is collision that earns insight, not a panel of identical answers.

## When to Use

- Stakeholders would clash on purpose or trade-offs
- A roundtable perspective is more valuable than a single recommendation

**Do not use when:** parallel implementation work (`dispatching-parallel-agents`).

## Process

1. **Cast 2–4 roles** using functional labels only: **Analyst**, **PM**, **Architect**, **Implementer**. Never trademark personas. State each role's stake in one line.
2. **One woven exchange.** Present short turns back-to-back (`**Analyst:**` …). Distinct diction; unequal spotlight; no memo stack.
3. **Clash without reconcile.** Challenge and faction are allowed. Do not force reconciliation, fake consensus, or a premature synthesis bow.
4. **Pull the user in.** Characters talk to the user and each other — challenge, tease, put a question back. The user is a guest in the argument, not an external facilitator.
5. **When it sags**, change something: new voice, name the impasse, ask where to take it. Do not invent takeaways unless asked.
6. Stop when the user signals done. Markdown notes only — no HTML keepsakes or runtime scripts presented as required artifacts.

### Clash rules

- Every voice must be unmistakably itself (hide the labels and you would still know who spoke).
- Overlap between roles is signal, not duplication to erase.
- Clean consensus that took no effort is where the party dies — resist the urge to tie a bow.

## Red Flags

| Thought | Reality |
|---------|---------|
| "I'll synthesize agreement now" | Forced consensus kills the signal of the clash |
| "Spawn implementers in parallel" | Wrong skill — use `dispatching-parallel-agents` |
| "Balanced equal turns every round" | Unequal spotlight is fine; variety beats a panel |

- [ ] Roles are functional labels only (Analyst/PM/Architect/Implementer)
- [ ] No forced reconcile
- [ ] User was pulled into at least one direct question when clash mattered
- [ ] No shortcut paths that skip the conversation; Markdown notes only
